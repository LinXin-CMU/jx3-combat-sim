# 苍生铸世测试服回归

本目录集中存放苍生铸世测试服新增的资源、规则、宏和版本边界测试。

从 `backend/` 执行：

```powershell
cargo test
```

当前后端仍以 `src/main.rs` 为二进制入口，核心类型尚未拆为 library crate。这些测试通过 `#[cfg(test)]` 和 `#[path]` 从相应模块挂载，以访问必要的内部接口；生产构建不编译测试代码。测试文件不放在 `src/`，本目录也不创建独立的测试入口 `main.rs`。

浏览器和 HTTP 的一次性检查产物不进入源码或版本数据目录。运行验证时使用独立端口与临时 userdata，结束后停止测试进程并清理临时目录。
