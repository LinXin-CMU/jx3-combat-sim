## 扫描方法

1. 使用固定规则检查密码、token、API key、Authorization、Bearer 和私钥头等高风险模式；
2. 使用 `detect-secrets` 的默认插件集并关闭网络验证，避免把候选内容发送到外部；
3. 对体积较大的数值表使用定向规则，避免通用熵扫描将大量游戏数值误判为秘密；
4. 扫描输出只记录文件、行号和规则类型，不输出候选秘密全文。
