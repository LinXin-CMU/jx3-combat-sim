## 截图规则

- 使用干净的演示账号和固定可复现场景；
- 不出现用户名、Cookie、token、公网地址、本机绝对路径或私人聊天内容；
- 同一组案例使用一致的版本、心法、属性和时间长度；
- 截图必须能对应到输入、输出和设计结论，避免只展示复杂界面；
- WebP 建议宽度 1600px 以内，兼顾 Git 体积和网页可读性；
- 原始录屏和大视频放在仓库外，仓库只保存压缩图和链接说明。

## 90 秒 Demo 结构

1. 0–10 秒：一句话问题与项目定位；
2. 10–30 秒：配置场景并运行确定性模拟；
3. 30–50 秒：时间轴定位损失来源；
4. 50–70 秒：优化器或 Agent 提出候选并做反事实比较；
5. 70–85 秒：展示量化提升、失败边界和证据；
6. 85–90 秒：架构与个人职责收尾。
