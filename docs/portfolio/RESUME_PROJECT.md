## 推荐正文

### 苍云器灵｜MMO 战斗模拟与 AI 策划实验平台

个人作品集，以《剑网3》苍云职业为研究对象，将循环、配装和宏优化问题转化为可复现的数值实验。项目设计与验收由作者推进，编码与迭代使用 AI 辅助。

- **战斗与数值建模：**拆解技能、怒气、体态、Buff、奇穴与秘籍的联动，建立版本化规则和共用伤害链；通过 DPS、技能构成与时间轴对比，分析循环节奏与资源利用。
- **宏策略验证：**将手动循环转为分体态宏，结合条件生成、算法调优与同场景模拟迭代；单一 300 秒案例中，最终双页宏保留原手动轴约 **98.35% DPS**，页长为 **87 / 73 字**。
- **Game × AI 应用：**设计模型自主选工具的诊断流程，结合版本攻略检索、机制上下文和模拟器 A/B 对比；支持时间轴定位、装备替换比较、宏蒸馏与任务反馈导出，保留可复现证据。
- **原型交付：**完成 Rust / Axum 与 Web 交互原型、独立用户后台及 HTTPS 演示部署；当前 **337 项 Rust 测试通过、1 项忽略**，支持会话持久化和脱敏调试。

## 面试时解释这条量化结果

“我研究的是手动操作策略如何压缩成可执行宏。宏有条件表达、体态和字数约束，所以我让算法先生成并调优候选，再让 Agent 根据模拟结果修改并复验。一个 300 秒冻结场景里，最终宏从手动轴的 296.85 万 DPS 保留到 291.96 万，保留率约 98.35%。这是模拟器内的单例，不能代表所有循环，也没有把游戏内效果说成已经验证。”

- “支持百人并发”：目前只是 100 个 worker 的配置上限，没有对应压测。
