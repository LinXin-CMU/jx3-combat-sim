# 苍云器灵｜《剑网3》苍云战斗模拟与 AI 分析平台

基于 Rust 模拟《剑网3》苍云门派的战斗逻辑，用于评估技能循环、搜索配装方案、生成并验证宏，以及通过自然语言分析战斗问题，为输出手法与装备选择提供量化依据。

- **战斗逻辑建模：**实现技能伤害、怒气资源、体态切换、Buff、奇穴、秘籍与装备特效建模，支持两个版本及分山劲、铁骨衣两种心法，通过 DPS、伤害构成和技能时间轴分析循环表现。
- **配装搜索算法：**按套装与特效分组，结合 Pareto 剪枝筛选装备组合；大候选池采用二阶属性收益拟合预筛，再基于当前循环进行模拟复算，比较属性分配与套装搭配的收益。
- **宏生成与验证：**解析宏条件及分体态执行逻辑，从技能轴提取释放条件，结合剪枝、调序与参数搜索生成候选宏；通过同场景模拟对比伤害和技能分布，验证宏对原循环的复现效果。
- **Game × AI 交互：**接入版本攻略知识库与模拟器工具，使 Agent 根据自然语言问题检索机制、诊断循环、对比配装并迭代宏；支持引用溯源、技能悬停预览和时间轴定位。
