# Agent 战斗策划分析规范

状态：已对齐暗影千机（2026）本地知识快照与当前 Rust 实现；用于约束 Prompt、工具路由、评测和作品集讲解。

## 1. 产品目标

Agent 的价值不是复述 DPS 卡片，而是把一个开放的战斗问题收束为可验证的策划判断：

1. 先陈述本轮直接观察到的事实；
2. 再提出有资料或时间轴支持的最小诊断；
3. 最后给出只改变一个变量的实验与预期取舍；
4. 明确哪些结论只属于攻略知识，哪些已经被当前模拟器验证。

推荐报告顺序：`结论 → 主要瓶颈 → 原因与取舍 → 下一步最小实验 → 证据边界`。

## 2. 客户端与版本硬边界

| 问题范围 | 可用知识资料 | 可用模拟器 | 允许形成的结论 |
| --- | --- | --- | --- |
| 旗舰端分山劲 | 当前赛季分山白皮书、系数、技改、延迟与实战资料 | 是 | 当前场景数值、时间轴和强类型候选对比 |
| 旗舰端铁骨衣 | 当前赛季通用/铁骨资料；资料完整度不足时必须声明 | 是 | 当前场景数值；机制解释受资料完整度限制 |
| 无界端分山劲·悟 | 当前赛季无界白皮书 | 否 | 仅知识说明，不能生成本项目模拟数值 |
| 历史赛季 | 用户明确指定的赛季资料 | 仅对应已实现归档版本 | 历史事实，不能静默替代当前版本 |

任何包含 `无界`、`分山劲·悟` 或 `Wujie` 的问题，Orchestrator 只向模型暴露知识检索，不暴露模拟、时间轴和候选对比工具。混合客户端对比可以解释资料差异，但必须拒绝数值横比，并固定声明：

> 这是知识资料说明；计算器未实现无界端，未经过本项目模拟验证。

## 3. 当前赛季的策划分析语言

暗影千机分山循环的有效分析不应只问“绝刀打了多少”，而应区分：

- 高质量技能的数量：在相同战斗窗口内实际完成了多少核心输出事件；
- 高质量技能的质量：核心技能是否落在血怒、援戈、业火等有效覆盖内；
- 资源转化：怒气与援戈层数是否转化为高价值技能，而不是只观察期末数值；
- 时间结构：公共调息空档、冷却等待、爆发错位与持续时间窗口；
- 实战稳健性：网络、按键、机器和服务器延迟会改变技能数量与增益覆盖，木桩极限不等于实战最优；
- 全局取舍：允许局部技能延后，前提是同一场景 A/B 证明全局收益或覆盖质量更高。

这些词只能在对应证据存在时写成诊断。当前工具没有观测到怒气损失、流血断档或增益覆盖时，只能把它们列为下一步假设，不能写成已发生的问题。

## 4. 资料角色与冲突处理

| 资料 | 主要用途 | 使用限制 |
| --- | --- | --- |
| `暗影千机：分山劲白皮书` | 当前旗舰分山技能、奇穴、循环、配装与实战框架 | 攻略数值不能直接进入本轮模拟指标 |
| `暗影千机：分山劲·悟白皮书` | 当前无界端知识问答 | 永不进入旗舰战斗候选或模拟解释 |
| `苍云技能系数汇总（2021-2026）` | 当前系数与技能身份交叉核对 | 必须限定在“暗影千机（2026）”段落 |
| `苍云历次技改汇总（2014-2026）` | 设计意图、正式服后续修正与历史演进 | 编年文档中的旧条目不能当当前事实 |
| `低延迟是打高DPS的先决条件` | 延迟来源、帧边界与实战稳健性 | 只能解释敏感性；本轮影响仍需候选对比 |
| `苍云盾压重置率推导` | 盾压概率机制假设 | 只在场景/心法匹配且实现可观测时使用 |
| 实战与宏资料 | 玩家实践、候选手法与副本情境 | 不能替代确定性模拟，也不能把旧副本经验外推为当前机制 |

知识冲突时优先级为：当前场景版本与心法 > 当前赛季可验证正文 > 当前赛季编年文档的最新条目 > 明确指定的历史资料 > 仅元数据来源。资料中标注“失效”的段落即使位于当前目录也仍是历史材料。

## 5. 当前实现能力矩阵

当前 `2026_04_暗影千机` 实现包含分山劲与铁骨衣数据目录，以及援戈、业火麟光、惊涌、嗜血、阵云结晦、绝返、麾远、赴敌、陷阵、锋鸣等脚本/奇穴路径。Agent 可以读取冻结场景，执行基线模拟、强类型候选对比和时间轴诊断。

仍需诚实暴露的限制：

- 无界端没有心法、技能、奇穴和循环实现；
- 模拟器输出是确定性期望，不是实战日志；
- 时间轴能观察公共调息空档、冷却等待、怒气范围和已暴露的 Buff 覆盖，但不能自动证明所有因果；
- 候选字段只允许修改已注册的强类型场景变量，不能用自然语言偷偷改技能公式；
- 铁骨衣当前赛季攻略证据弱于分山劲，资料不足时只能报告模拟事实和明确的知识缺口。

## 6. 输出验收标准

一份合格的专业报告应满足：

- 摘要先回答“当前最值得关注什么”，不叙述调用过程；
- 观察、诊断、决策不混写；
- 数值全部来自本轮模拟 Evidence，并绑定精确字段路径；
- 攻略只解释机制、候选来源和玩家实践，并显示赛季及原始超链；
- “最优”“毕业”“必选”等结论必须有同场景候选排序证据；
- 差距很小时，不凭直觉宣称更稳健，而是提出延迟或时间轴敏感性实验；
- 无界知识回答固定展示未实现、未模拟边界；
- 没有足够证据时，给出最小补证实验，不让整轮以检索预算耗尽刹停。
