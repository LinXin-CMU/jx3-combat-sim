# 多循环工作区（2026-09-30）

循环编辑区支持多页并排对照。主循环默认最左且不能隐藏、删除；其他页可从当前循环复制或从空白创建。点击页签或循环内容切换当前页，状态栏、技能栏、统计及时间轴跟随高亮页。页头 `⋯` 可命名、交换页面、选择 Redline 对比页、隐藏或删除。交换可见页时互换位置，列宽保持；选隐藏页时替换当前页，主循环例外，仅在旁边恢复隐藏页。位置随账号保存。

鼠标悬停当前页标题自动显示半透明编辑工具条，包含编辑/写宏、复制和新建；移开后收起，也可按 Esc 收起。键盘聚焦标题同样可展开。不再显示展开箭头、“页面”按钮和“前台”文字。只有 32px 标题行占布局高度，Redline 统计直接显示在标题按钮内，长内容省略并提供完整悬停提示。

拖动页间边界仅调整相邻两页：先固定所有可见页的实际宽度，再保持这两页总宽不变，其他页的位置和宽度不动。双击分隔条或按 Home 均分相邻两页，左右方向键微调。最后一页不显示分隔条。

各页共用当前版本、心法、配装及战斗环境；技能序列、预释放、换行、释放偏移、引导跳数及宏内容分别保存。导入、导出、技能编辑和器灵读取的都是前台循环。写宏模式保留原模板/实际循环布局，退出后恢复多页。

默认对比技能顺序，复用 `Jx3MacroAlignment` 的 LCS 对齐：基准页独有技能为红色，前台页新增技能为绿色。同一技能发生一次插入或删除，不会把后续全部判为不同。可切换“含时间和状态”，按写宏对照的一帧容差和状态字段比较；未回放的基准页会使用完整前台场景请求在后台回放，不切换前台。对齐仍遵循现有组件每侧 2048 个主动技能的上限，超出时明确提示。

## 实现约束

- `frontend/loop-tabs.js` / `.css` 管理页、布局及存储；字体、配色和缩放使用现有设置。
- 保留唯一原始 `#sim_sequence` DOM 容器和原编辑事件，将各页真实技能节点迁入/迁出。原有框选、复制放置、拖拽排序、工具栏和弹层继续使用原实现。
- 非前台空白区第一次鼠标按下因节点迁移被浏览器重定向至稳定父容器，由原 `beginSelection` 接续，避免要求用户重新拖一次。
- 每次切页清理选择/预览临时状态并使旧模拟请求失效；手动模拟、空循环请求、宏模拟、插入预览和宏固化均检查请求或页面归属。
- `GET/POST /api/loop-tabs?version=…&mount=…` 存在当前隔离 worker 的 `JX3_USERDATA_DIR/loop_tabs/`。路径分量限制为字母、数字和下划线，串行原子替换写入。
- 一份文档含共享场景、各页内容与布局。服务器为账号持久存储，本机副本按已核实的账号/版本/心法隔离，较新的未同步修改可在刷新后恢复。写服务器前复核登录身份。
- 新数据不进入通用 localStorage 设置同步。已登录用户的首次迁移只读取启动时收到的本账号旧设置，不能继承前一账号残留的本机单循环快照。既有旧存档不删除。

# 对照同步滚动（2026-09-30）

选择 Redline 对比页后默认开启双向同步，页面“⋯”菜单中的“同步滚动”可以关闭；关闭仅对当前对照生效，重新选择对照后恢复开启，不写入用户的永久偏好。滚动使用已算出的技能配对构建位置映射，按显示帧合并滚动事件，避免每次滚动重算对齐。仅联动当前对照的两页。前台与后台底部布局相同，切页保留各自滚动位置；拖动后台原生滚动条不激活该页，仍可正常拖选、复制和拖拽技能。
