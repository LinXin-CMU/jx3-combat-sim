## 问题

旧 Golden 于 2026-05-01 捕获，但没有记录游戏版本、心法、场景哈希、数据哈希或源码提交。当前代码一度又把所有版本枚举重定向到 `2026_04_暗影千机`，因此旧快照无法证明属于山海源流、暗影千机或两者之间的某个开发构建。

旧文件已原样移动到 `backend/tests/golden/legacy_unversioned/`，只作为历史证据保留，不再参与通过/失败判定。

## 本次修复

- 恢复 `2025_10_山海源流` 与 `2026_04_暗影千机` 的独立数据路由；
- 恢复两套版本的独立 Rust 技能/Buff 脚本路由；
- UI 的版本列表重新暴露两套正式服数据；
- 版本切换同时重载技能、奇穴、秘籍、团队增益和阵法；
- `/api/mounts/switch` 支持 `persist=false`，回归测试切换版本时不改写本地用户选择；
- Golden v2 同时校验版本、心法、场景哈希、数据/脚本哈希、fingerprint、DPS、总伤害、事件数和战斗时长；
- Golden 更新默认拒绝脏工作区，并记录生成时的 Git commit。

## 对旧 Golden 的判断

旧绝云宏 fingerprint `9c0b1069c1106484` 与当前 2025、2026 均不匹配；坚铁寒甲同样不匹配。旧快照因此不能直接归属任何一套当前版本。

旧“简单循环”的 fingerprint 与当前 2026 相同，但保存的 DPS 为 227,020.837326，当前为 227,068.133333。旧校验器只比较 fingerprint，所以此前的“通过”没有捕获数值漂移。Golden v2 已修复这一缺口。
