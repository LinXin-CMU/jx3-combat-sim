# v43：局部序列证据与合法候选

## 已核实根因

检查反馈对应的本地私有复现记录（仅读取，没有改写）：

- 原始工具证据的五个目标时间为 131.8125、162.9375、187.3125、242.375、263.9375 秒。它们前面都有两次 50 怒绝刀，属于同类斩刀后第三发绝刀结构；目标施放前体态均为 blade。
- 模型请求中的压缩证据，前两刀只剩邻近一两次操作，后三刀 context 为空。模型把缺失观测解释为孤立单发，并把前两刀解释为第二刀，分类错误。
- `restore_compact_timeline_windows` 曾只保留前后一个事件；进一步大小压缩从最后窗口起逐个 pop 邻居，导致各目标上下文不对称。
- 后续模型还把局部补丁的原始操作编号自行顺延；实际服务端已倒序应用补丁，调用方应保持原始编号。
- 现有模型机制上下文包含技能名，但缺少运行表的施放体态和基础资源条件。

## 修改

- 完整短窗口保留前后最多四个事件。压缩先减状态字段，而非把邻居逐个删成空窗；无法保留的窗口明确标记 partial。
- 命中索引增加从现有证据生成的 `local_sequence` 字符串，保留有序技能及目标标记，即使详细状态窗口被移除，局部顺序仍可读取。
- 体态与操作编号经过重复压缩仍保留。新增五个目标、重复两轮压缩的回归检查。
- 机制上下文由当前运行表生成技能施放体态、基础资源、体态切换和连招条件。
- Prompt v43 说明候选合法性、原始操作编号、完整序列/局部补丁的区别，以及技能系数和脚本效果修改尚未开放。没有赋予任意文件写入或规则修改权限。
- 浮窗取消内部滚动和固定高度裁切，多位置改为上一处/下一处切换；自身和目标 Buff 横向紧凑排列，定位按钮完整保留。

## 边界

本次修复证据传输和工具使用说明，不改变战斗引擎。五刀同属第三发只纠正结构判断，不证明其取舍相同或存在净优化收益。技能系数/脚本效果实验尚需单独建设隔离工具及授权流程，不能靠提示词取得执行能力。
