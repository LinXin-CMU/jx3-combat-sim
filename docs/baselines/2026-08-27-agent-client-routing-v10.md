# Agent 客户端与心法路由基线（2026-08-27）

## 产品规则

- 未明确客户端时，默认旗舰端；未明确版本与心法时，继承当前计算器场景。
- 明确出现“无界”“分山劲·悟”或 `Wujie` 时，切换为无界知识问答且不暴露模拟工具。
- 用户明确说出分山劲或铁骨衣时，显式心法覆盖当前场景的检索心法。
- 资料在 BM25 与 Dense 召回前完成客户端、心法和版本硬过滤，模型不能用提示词绕过。
- 身份与作者点查不受客户端过滤，但不能据此形成当前战斗结论。
