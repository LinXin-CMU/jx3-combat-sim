# Agent 自适应证据选择基线（2026-08-27）

## 产品行为

- `top_k` 不再暴露给模型；证据数量由服务端决定。
- 查询先判别循环、宏、配装、副本、机制或通用意图。
- 白皮书、实战、机制、宏和通用资料只参与软加权，不设置固定配额。
- 高置信检索优先较早停止；低置信检索扩大候选；证据角色单一时可为覆盖度追加资料。
- 客户端、心法、赛季、事实资格和最多 8 篇资料仍是安全上限，不作为每轮目标数量。
- 检索响应返回 `selection` 摘要，供 Orchestrator 判断停止或仅做一次必要的查询改写。

## 验收

- Prompt：`agent-system/v11`；
- Embedded 固定集：23/23；
- 版本、来源、拒答和客户端断言：29 条；
- 高置信测试返回资料少于低置信测试；
- 来源角色只改变排序与扩展决策，不会越过版本和客户端硬过滤。

真实 `deepseek-v4-pro` 同题复测中，服务端两次检索各自选择 4 篇候选，最终报告只引用其中 2 篇；不再机械返回或引用 5 篇。模型使用第二次改写检索补充了延迟资料，全程未运行用户明确禁止的战斗模拟。
