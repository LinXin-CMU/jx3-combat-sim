# 循环页签审计与修复

## 已确认的问题

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 首次进入副页宏占位、角标不更新 | 只回放前台，副页只有被选作状态对照时才可能回放 | 可见页自动回放，隐藏页按对照依赖回放；后台串行，不重复运行相同场景与输入 |
| 切焦点后其他副页差异消失 | 每次清空全部标记，却只计算当前页一组差异 | 计算所有可见页启用的对照关系，当前页关系优先展示；首处差异按各自关系定位 |
| 副页默认无对照 | 默认 `compareTo` 为空 | 副页默认对照主循环；显式关闭后保存选择。旧数据中的未标记空值迁移为默认对照 |
| 后台模拟参数容易漂移 | 独立拼请求且依赖前台最后一次请求 | 共享完整请求构造函数，包含装备、团辅、目标、奇穴、秘籍、起始状态、延迟、预释放及固化记录；主循环为空也可回放副页 |
| 延迟结果可能关联错页面 | 请求持有旧容器，切页期间容器和实际焦点改变 | 返回时检查页面存在、完整场景、序列输入，重新取得当前容器；后台不更新前台侧栏及技能栏 |
| 对照滚动仅连接一组 | 只保留当前页的一条关系 | 同步所有启用的可见对照关系，以访问集合避免循环；可单独关闭，恢复位置不触发连锁滚动 |
| 菜单操作抢走焦点 | 页头捕获事件无条件切页 | 页名和内容点击切页，命名、选择对照和设置菜单不切页 |
| 拖拽后的引导设置错位 | 引导跳数按原下标保存 | 设置跟随技能块，生成请求时按新位置重建下标；预释放不占主动序列下标，复制和导入保留设置 |
| 重复刷新逐渐累积提示处理器 | 每次装饰重复绑定鼠标事件 | 技能提示只绑定一次，更新当前内容；清除失效施放时间与旧交互处理器 |
| 框选取消不完整 | Escape 仅在进入放置阶段时注册 | 框选及其操作条均可用 Escape 取消 |

界面统一使用“差异分析”，不显示 Redline。默认比较技能顺序，可切换为含时间和状态。主循环保留；循环内容不自动覆盖或删除。手动关闭对照和同步滚动按账号、版本、心法保存。

缓存校验包含完整场景和该页输入。切到已回放且仍有效的页，直接显示真实缓存结果并恢复普通编辑；变更场景或输入则重新回放。失败后台请求不会不停重试，菜单提供“重新回放”。显示模式与辅助信息更新使用已有结果，无须再发模拟请求。

## 验证

浏览器使用隔离 worker，页签 fixture 在浏览器截获，未写入真实用户数据。覆盖三页首次加载与素材、默认对照、前后台环境请求一致、三页同步滚动、单页关闭同步、切焦点保留滚动与缓存、菜单不抢焦点、相邻宽度调整不改变第三页、设置保存并重载、预释放与引导索引、真实拖拽、复制页、鼠标框选及 Escape 取消、隐藏后从交换页面恢复及重命名。三个初始页各运行一次，缓存切页和显示设置不增加模拟请求。

额外人为延迟旧场景的后台响应，改变公共网络延迟并完成前台新回放；旧响应未装饰副页，后台随后回放新场景，切页后请求保持新的延迟参数。

暗影千机 / 铁骨衣现存 351 步固化场景再次验证：工作区读取保留 351 份固化记录，实际成功释放 351 次，跳过 0 次，与原回放无分歧。完整场景和结果仅作本地留档。

相关前端语法、固化纯函数、对齐及 Harness / 合成界面共 23 项测试通过。334 步原宏仍验证：无有效缓存时提取与独立验证共 2 次请求，有有效缓存时仅 1 次验证；导入导出回放一致，故意改变验证结果时保留原宏。此次只修改前端交互和请求传递，未修改后端战斗规则；无需重启服务。可复现浏览器检查：`tools/loop-tabs-ui-test.js`，运行目标必须是隔离 worker。
