# 暴怒资源与 Agent 溢出证据

## 问题与修复

用户反馈中，模型将“工具没有暴怒字段”误述为“暴怒未建模”，随后用普通怒气的 18 次、155 点溢出回答暴怒问题。此前模拟器已有独立暴怒、上限和快照，但没有溢出流水；Agent 时间轴投影也遗漏了暴怒快照。

- `src/berserk.rs` 记录时间、来源、请求增量、实际增量、前后值、上限和溢出量。血怒回复、阵云消耗分别命名，不归按每个整秒记账，不依赖是否恰好施展技能。初始化满暴怒不记为溢出，恰好达到上限也不算损失。
- Full 模拟返回 `berserk_transactions`；Lite 保留原资源计算但不分配流水。正式服及未启用暴怒的场景不产生该流水。
- Agent `analyze_timeline.berserk` 和方案比较分别给出暴怒是否建模、流水是否可用、总产生、实际获得、消耗、溢出事件数、溢出总量与来源汇总。
- `inspect_timeline_events` 增加 `berserk_overflow` / `berserk_cap`，按独立资源事件分页，返回准确时间。血怒事件可关联实际施放编号和宏行；被动回复没有施放归属，前后技能编号仅提供位置上下文。
- Agent 事件状态与轻量索引保留暴怒前后值和上限；模型投影、压缩及紧预算分页保留暴怒证据，不能静默跳过被裁掉的资源事件。
- Prompt v50 明确区分 rage 和 sun，禁止用怒气代答暴怒，禁止从缺少工具字段推断机制未建模。保持既有 12,000 字节提示词上限和工具权限边界。

这次没有改写旧会话、报告、宏或配装。旧反馈包不会自动更新，需刷新并重新发起分析。没有重跑原反馈包的完整场景，不能把验收场景结果当作原循环的修正结论。
