# 2026-09-14：属性等级隔离与测试服铁骨 Agent 修复

版本：`v2.0.12-20260914`。

## 问题与修复

50级公式启用后，属性默认档及多套配置仍只按心法命名，因此测试服会读取130级旧面板。旧输入328941体质、138791无双在50级参数下产生266299攻击、1500.74%破防。共享装备缓存已经使用压缩后的条目，正式服与测试服却共用该缓存，进一步造成配装和存档口径不一致。

- 属性默认档、多套配置及共享输入按人物等级隔离；130级原路径保持不变。50级已有独立面板优先，首次使用时由当前配装生成对应等级的属性，没有配装则使用裸装默认值。
- 旧属性能够与保存配装逐项对应时，读取时按50级装备重新计算；不按任意比例缩放手填数值，不批量重写原存档。
- 装备、附魔及五彩石目录按50级／130级匹配；详情、配装计算、搜索、属性收益和 Agent 配装工具读取相同等级数据。
- 修复神兵·无双档位数值：武器45320在50级每层15无双，130级仍为1272。该修复不改变叠层和持续时间。
- 页面启动等待属性加载后才模拟或捕获 Agent 场景；切换心法时不提前保存裸装默认值，旧共享输入不再覆盖属性面板。
- 移除 Agent 对苍生铸世测试服只允许分山劲的过期限制。铁骨衣场景可创建、校验哈希并运行，两个心法的场景身份仍然独立。
