# Agent 知识数值证据绑定基线（2026-08-27）

## 问题

旧校验器只允许正文数字复述确定性模拟指标。纯知识问答没有模拟指标，因此模型即使逐字引用攻略中的宏阈值、延迟或加速档位，也会触发 `numeric_prose_claim`，使有来源的报告降级为“部分通过”。

## 设计

- 模拟数值仍必须绑定本轮模拟证据、数值字段和 JSON Pointer。
- 知识数值只能逐值匹配该结论实际引用的 `fact_eligible` 资料标题、章节、片段或赛季元数据。
- 未引用资料中的相同数字不能借用；不可用于事实的资料不能放行数字。
- 百分号语义必须一致，不能把来源中的 `30%` 改写为 `30`。
- 攻略数字只是版本化知识陈述，不会进入模拟指标卡，也不能证明当前场景收益。
- 对 `current_only`、`cross_version` 和 `reference_lookup`，供应商重复填写的 season 视为冗余字段；实际版本范围仍由服务端 scope、问题文本和索引过滤器确定。
