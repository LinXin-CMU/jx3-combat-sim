## 学习了什么

- 四个训练页来自两个源宏，按页提取8种匿名条件链结构。只统计资源、存在、层数、目标、技能、上次技能、时间条件类别及原生连接符；不携带技能名、Buff名或数值阈值。这些静态统计是结构建议，不是成功标签。
- 使用27维决策前特征学习通过概率和验证成本，包括改动比例、条件复杂度、时间叶变化、同动作重复度、观测窗口覆盖、等待与优先级冲突。目标前缀长度、候选回放结果、来源姓名不能进入预测特征。
- 成功标签要求原生完整终点认证；失败标签要求原生确定的首次分歧。静态筛选、UNKNOWN、取消、截断、预算结束和基础设施错误不构成负例。
- 每个起点、失败分支保留自身场景合同、正文摘要和轨迹来源。只在该路径上提取特征，不合并互斥候选的状态；模型不保存这些状态供新任务复用。

模型在独立来源家族的120条标签上冻结评估：

| 指标 | 原透明启发式 | 学习模型 |
| --- | ---: | ---: |
| Brier误差，越低越好 | 0.1660 | 0.0589 |
| AUC | 0.9035 | 0.9471 |
| 分类准确率 | 73.3% | 93.3% |
| 六个自身路径候选组的首选通过数 | 3/6 | 4/6 |

同路径首选的认证节省字数合计147→166只是离线排名代理，不是整轮压缩收益。验证只有一个来源家族，样本存在同场景相关性；这些指标不能证明跨版本、引导、多页合成或其他玩家配置的泛化。

更强的简单对照是现有观测窗口静态筛选：同120条验证标签上，它也判断正确112条、准确率93.3%，与学习模型相同；将其0/1判断直接作为概率时Brier为0.0667。因此学习并未证明分类能力超过已有静态筛选，不能只用较弱的旧概率启发式对照宣称算法突破。训练工具的评估输出也保留这项对照；静态筛选本身仍不能认证宏。

## 搜索接入与局部提速

`LearningSession.from_prior`校验数值schema、原生等优先级右结合语法、原生程序摘要和版本/心法适用范围，在新任务建立冻结会话。只载入权重及匿名结构，不导入旧合同、宏正文、候选标签或轨迹。测试任务不更新模型；同训练家族不能伪装成保留测试组。

候选排序保留探索与全部已生成候选；昂贵生成器按最多16份候选的预读窗口排序，不先遍历整个流。最佳宏仍只由完整原生认证更新，第一阶段没有字符目标，第二阶段不改变原场景、终点和容差。

区域搜索改为先以位集构造原生右结合条件库，再由SAT联合选择整条条件、动作、插入位置和顺序。不同时间叶保留不同唤醒来源；当前真值相同的非时间表达式只在该样本范围用于提案去重。自由条件链后端`backend="chain"`仍可显式用于扩展；有限候选库UNSAT不能证明整份循环或所有合法宏无解。

固定长例的一个血怒区域，旧条件链建模1.671s、求解504ms UNKNOWN、总2.337s；整条件库建模0.451s、求解37.5ms有限UNSAT、含候选构造总0.692s。两个查询空间不同，此结果说明有限候选库查询更便宜，不能把UNSAT与UNKNOWN当相同证明结果，也不能据此宣布全搜索快3倍。
