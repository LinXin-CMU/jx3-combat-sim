# Agent Prompt v21 精简基线

## 目标

将默认提示词从“规则总集”改成“领域分析操作手册”。安全、工具权限、预算、版本工具暴露、证据引用和报告校验继续由 Rust 服务端执行，不再通过重复的警告句要求模型自我约束。

## 改动

- v20 保留不动，继续支持历史会话按版本和哈希复现。
- 默认版本切换到 `agent-system/v21`。
- 提示词从 16,748 bytes 降到 8,124 bytes，减少 51.5%。
- 删除重复的安全宣言、完整字段规则和服务端已经执行的防线。
- 保留诊断分层、循环与宏语义、知识版本、保存方案、配装分析和自然中文表达。
- DeepSeek 对结构化输出 schema 的遵循不稳定，因此保留一份短 JSON 骨架；它属于输出接口说明，不属于防御话术。

## 真实模型验收

同一冻结场景、同一显式优化问题、DeepSeek V4 Pro：

1. `run-1a06177f32e-0`：分析和实验有效，但模型自行创造了另一套报告字段，最终 `invalid_report_json`。该失败促使短 JSON 骨架回归。
2. `run-1a0617ac7c1-0`：状态 `completed`；完成场景、知识、基线、时间轴和同场景对比，最终正确生成 `AgentReportContentV1`。

最终运行的四次模型请求为 39,796、56,983、62,029、70,507 bytes，全部低于 72 KiB 上限。第一轮相较 v20 同场景基线的 48,601 bytes 减少 8,805 bytes。

## 回归

- Rust：231 项通过。
- v21 单独检查提示词低于 10,000 bytes，并保留推导状态、同场景比较、Buff 覆盖率、宏 AST、配装黑话和报告协议关键字。
- 本地服务保持只监听 `127.0.0.1:3005`。
