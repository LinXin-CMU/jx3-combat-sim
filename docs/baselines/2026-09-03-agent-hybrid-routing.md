# Agent 混合任务路由基线（2026-09-03）

## 问题

旧路由按固定顺序查找关键词，第一个命中项直接决定 Playbook。一个问题同时出现“保存、宏、空转、实战”等词时，前置词可能错误锁定任务和工具链；没有命中词的自然改写只能进入通用分析。

## 当前方案

任务选择按以下优先级执行：

1. 快捷入口发送强类型 `task_hint`；它只选择 Playbook，不授予额外权限。
2. 自由输入对全部任务同时计分，融合加权词法信号、产品页面弱先验和本地 BGE 多示例语义相似度。
3. 路由保留前三个候选、置信度和策略，随完整调试信息导出。
4. 无法拉开差距时进入通用 Playbook；只有“继续、接着、下一步”等明确短追问才继承上一轮任务。
5. 版本、客户端、工具白名单和只读权限仍由服务端确定，不由路由分数决定。

Embedded 模型优先从 `JX3_KNOWLEDGE_CACHE_DIR` 的完整本地快照加载。网络不可用时不再因为 Hugging Face 元数据请求失败而降级 BM25；缺失或损坏时仍显式降级并记录原因。

## 隔离实测

- 结构化路由、候选排序、歧义降级、旧会话反序列化：21 项领域单测通过。
- Rust 全量：247/247。
- Agent 只读工具评测：20/20，非法写入 0，userdata 不变，运行态恢复。
- 知识检索：159 篇、3796 分块，Embedded `hybrid_rrf`，固定集 Recall@5 24/24。
- 3017 临时 userdata 的自由输入冒烟：保存方案、循环基线、循环衔接故障、装备选择四类自然改写均进入预期专用 Playbook；无关天气问题进入通用降级。
- 另一条“面板上这个值从哪算的”保持通用分析，说明当前策略宁可保守降级，也不在相似度不足时强行分类。
