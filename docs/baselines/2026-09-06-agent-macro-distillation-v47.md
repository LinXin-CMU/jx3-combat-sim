## 主线

## 复用与边界

- InputCast 映射与旧前端 `/api/macro/from_sequence` 一致，使用完整释放前状态、triggered 与 is_main。
- GenOptions 从空 JSON 反序列化，沿用 serde 的旧生成默认值（128 字符等）；未使用字段为零的派生 Default。
- 生成结果为未对比初稿，带 baseline、规则正负样本/F1/候选条件、丢弃原因、每页字数及场景证据身份。
- 工具复用本轮基线模拟缓存，消耗既有模拟预算；不修改模拟器公式、宏引擎或用户保存的宏。
- 对比结果额外包含 macro_pages，使用旧前端正文计数口径（UTF-16 长度，含正文换行，不含分页标记）。超限是明确状态，不静默截宏。
