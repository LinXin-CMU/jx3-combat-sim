# Agent K5B 真实模型分层基线（2026-08-27）

## 结论

K5B 用同一组 6 题分别评测 DeepSeek V4 Pro 与 V4 Flash，每题单次运行、零重试。评测拆分为规划、版本、证据和表达结构代理四层，不把最终状态或一次漂亮回答冒充“模型准确率”。

本轮确认了两个工程问题并完成修复：

- 赛季与分类过滤值改为从本地索引动态生成的枚举；两次知识检索后，Orchestrator 确定性移除工具并要求收束报告，不再允许第三次检索撞上预算；
- 兼容接口返回空正文时，不重试、不补写结论，而是保留本轮已经取得的只读证据和来源；失败响应的 token usage 进入账本。

## 固定题集与评分口径

题集位于 `backend/tests/agent_k5b_eval/cases.json`，覆盖当前版本知识、纯数值基线、资料假设到 A/B、指定历史赛季、无答案和越权请求。

- `planning`：是否走与任务匹配的最小工具路径；
- `version`：来源赛季与 `version_match` 是否匹配题目；
- `evidence`：资料与模拟证据是否承担正确职责；
- `expression_proxy`：只检查结论位置、信息层级、边界、机器字段泄漏和篇幅，不代表人工专业度。

综合分是适用层的简单平均，只用于定位回归，不是产品成功率。

## 能稳定宣称的结果

- 历史赛季题从初始的“三次检索后预算耗尽/无来源”，变为两次以内命中正确赛季；最后两轮 Pro 与 Flash 均为 version 100、source 3–5。
- 无答案题在最终运行中两模型均 completed，来源和数值均为 0，没有用其他攻略补位。
- 两次 `provider_response_empty` 在最终运行中被降级为 `partially_verified`，已取得的来源仍可展示；系统没有自动重试，也没有代替模型编写玩法结论。
- 最终 Flash 的“资料假设 → 强类型 A/B”题同时获得正确当前来源与模拟指标；Pro 在同题仍未形成合格双证据报告，说明模型稳定性问题尚未解决。
- 最终越权题中 Flash 正常拒绝；Pro 尝试调用未注册工具，但协议层在执行前拦截。作品集同时报告尝试与执行，不能只写“执行为 0”。

## 尚未通过的门槛

- 6 题样本只能发现失败模式，不能证明跨问题泛化；
- Pro 仍存在空响应、错误实验路径和一次越权工具尝试；
- Flash 本轮更稳定，但同一题集跨轮仍有来源缺失，不能据此宣称 Flash 永远优于 Pro；
- 表达代理分不评价战斗策划术语是否专业、推理是否深入。用户已明确把专业表达重写放到后续阶段。
