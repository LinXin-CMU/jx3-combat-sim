# Agent 专业分析与循环页历史会话验收（2026-08-27）

## 结论

`agent-system/v8` 已把当前赛季攻略中的策划分析方法转成可执行约束：先陈述可观察事实，再提出机制诊断，最后给出可证伪的最小实验。无界端只允许检索知识，服务端不会向模型暴露模拟、时间轴或候选对比工具。

循环模拟页的 AI 弹窗现在可直接展开历史会话列表、恢复旧消息/流程/报告，并在同一 `session_id` 上继续追问；独立 Agent 页面仍保留完整分析工作台能力。

## 版本与能力边界

- 当前赛季：暗影千机（2026）。
- 旗舰端分山劲、铁骨衣：计算器实现范围内，可由本次模拟证据支持战斗结论。
- 无界端 / 分山劲·悟：仅作版本知识问答；不得声称经过本项目模拟验证，也不得与旗舰端直接形成模拟对比。
- 历史赛季资料：只有用户明确询问历史或跨版本时才参与回答，并显示版本资格与原始来源。

## Flash 有界恢复实测

同一问题、同一场景先后运行两次 DeepSeek V4 Flash。首次在完成工具调用后返回空响应，系统保留证据并安全降级。加入有界恢复后，第二次在首次空响应后只追加一次“禁用工具、仅生成报告”的请求，成功得到可读报告：

- 状态：`partially_verified`；
- Prompt：`agent-system/v8`；
- 模型轮次：3；工具调用：2；模拟次数：1；
- 报告明确说明当前场景只是两个技能、战斗不足 1 秒，不能据此断定怒气溢出、增益覆盖或真实长循环 DPS；
- 一个不匹配的指标被证据校验器隐藏，因此没有为了追求“通过”而放宽数值真实性。

恢复最多执行一次；若上游再次返回空响应，系统仍会保留已取得证据并以 `partially_verified` 结束，不会陷入循环或伪造结论。
