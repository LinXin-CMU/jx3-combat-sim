## 已实现规则

| 内容 | 模拟器行为 |
| --- | --- |
| 盾刀、盾压 | 按公告提高基础伤害及系数；用户补充后盾刀一段攻击系数 2.8125、盾压 7.19375；回复怒气分别为 10、20 |
| 阵云结晦 | 移至第一重；无独立调息或充能，保留原公共调息；50–99 暴怒消耗 50，100–120 消耗 100 |
| 阵云一段伤害 | 50 档非侠士加成 76%；100 档非侠士加成 195%；新攻击系数已包含档位增幅，不再额外乘 1.75，隐藏秘籍二选一，走现有九步取整链 |
| 暴怒 | 仅新分山劲选中阵云时启用，上限 120；默认按完成脱战准备开场，初始 120（公告脱战每秒回复 10，充满需 12 秒） |
| 不归 | 战斗期间每个整秒回复 2 暴怒；血怒充能调息减少 3 秒，每次施展回复 50 暴怒 |
| 神威 | 需要阵云；开启二、三段，后续段不再次扣暴怒；每段保留 90 秒，过期回到一段；宏只写“阵云结晦”可自动转段 |
| 惊涌 | 移至第二重；无双等级常驻提高 20%；血怒不能叠加，其间斩刀、绝刀非侠士伤害加成分别为 100%、71%；移除旧额外惊涌伤害和破招加成 |
| 威压 | 第六重；盾压加 2 层、盾刀加 1 层，30 秒、上限 8；下次盾猛最多消耗 6 层，每层伤害提高 30%、返还 1 秒调息 |
| 残裂 | 移到混选池；盾猛调息减少 3 秒，额外回复 20 怒 |
| 锋鸣 | 盾飞充能调息减少 6 秒，保留施展后基础外攻提高 15%、持续 30 秒；删除旧盾飞伤害提高 100% |
| 奇穴 | 按公告重排 6 重及 12 项混选池；移除撤出的援戈、业火麟光、血壑、烨疆；校验新增核心依赖 |
| UI / 宏 | 暴怒条按用户截图改为橙金刀刃图标、黄绿色动态数字；模拟响应、日志前后快照均有暴怒值及上限；宏以 `sun` 判定暴怒，`energy` 判定格挡，保留 `berserk` / `baonu` 旧别名 |

新版禁用旧“雾海寻龙”实验性替代招式，防止绕过暴怒与神威前置；切回正式服后原有实验性设置仍保留。

`sun` 读取暴怒，`energy` 只读取格挡。`rage` 仍为普通怒气，`skill_energy` 仍为技能充能；`berserk` / `baonu` 是本模拟器保留的暴怒扩展别名。

新增奇穴未公布原生 ID，使用版本私有临时 ID：不归 `91001`、神威 `91002`、威压 `91003`、盾生锋 `91004`。威压、惊涌常驻效果、角斗场分别使用 Buff ID `91901`、`91902`、`91903`；查找和 UI 枚举均注册。

## 数据复用与范围

阵云按用户补充的 50 / 100 暴怒攻击系数实现：一段 5.33125 / 9.33125，二段 6.7125 / 11.725，三段 8.0875 / 14.1625。后续段锁定首次消耗档位；不再次扣暴怒，三段均不回复普通怒气。二三段删除旧非侠士 +200% 秘籍 `99342`，一段仅用本档 76% / 195%。

按用户明确要求，测试服删除全部五个破招伤害定义及对应脚本事件；正式服破招和装备破招属性保留。

三段固定伤害 73 / 97.5 / 124.5、武器系数 1、无视外防 100%、公共调息和姿态限制继续复用旧数据。100 档固定伤害和武器部分是否另有增幅尚未确认，当前不额外放大。命中延迟、范围和位移未建模。完整增伤和效果核对见 [阵云审计](2026-09-08-zhenyun-audit.md)。

公告未提供盾回距离与速度的映射，暂保留旧版时序。等级、装备、属性换算常量也沿用副本，当前用途是隔离验证首轮技改，不是已完成全量 50 级数据迁移。

当前模拟器没有玩家气血、队友护盾、化劲及多人位置状态。鸣金复活回格挡、盾生锋队友护盾与破盾后的化劲削减等更新奇穴文案，但不虚构其战斗收益。盾生锋关闭盾系招式贡献的盾压重置标记。

矢尽兵穷的已知 15 秒角斗场、场内闪刀无调息及流血伤害提高 200%已定义并通过脚本与 Buff 实现；公告和旧版仓库均无其完整主动招式调息数据，暂不新增可选主动按钮。流血快照路径按现有伤害链的第二步应用实时秘籍增伤；不影响没有该秘籍的正式版本。
