## Agent 自由正文

沿用现有 Agent 与工具循环，不新增策划专用路由或章节模板。报告新增可选 `body_markdown`，模型根据任务选择自然段、文章、表格或步骤。`summary` 用于会话摘要；数值、证据和可执行改动继续使用原有结构化字段。

定性讨论无需为了填字段而检索或模拟。自由正文附带的定性分析条目和建议可以不附实测引用；数值仍须通过已有证据校验。前端优先显示完整正文，证据指标折叠展示；复制正文不附加运行哈希等调试信息。旧报告和旧会话继续兼容。

真实模型试跑暴露了“文章写在 JSON 外、字段只写正文见上”的输出方式，解析器现会保留实质正文并执行相同校验。正文中的假设、当前场景、资料缺失与系统实现范围分别表达，禁止将一个心法的实测占比直接当作另一个心法的移植收益。
